# Brentq と Brenth の数学的・技術的差異に関するレポート

## 1. はじめに

本レポートは、`ellphi` プロジェクトに実装されている数値計算の根探索アルゴリズム `brentq` と `brenth` について、その数学的な原理と実装の詳細を記述することを目的とします。

## 2. Brentq: 逆2次補間法

### 2.1. 数学的原理

`brentq` は、Richard Brent氏が1973年に発表した論文で提案された、Brent法として知られる標準的なアルゴリズムです。この方法は、根が存在する区間 `[a, b]` を狭めていく手法であり、以下の3つの手法を効率的に組み合わせることで、ロバストかつ高速な収束を実現します。

1.  **二分法 (Bisection Method):** 最も安定した方法であり、区間の中点 `m = (a+b)/2` を計算し、`f(m)` の符号に応じて区間を `[a, m]` または `[m, b]` に狭めます。収束は線形ですが、確実性が高いです。

2.  **割線法 (Secant Method):** 2点 `(a, f(a))` と `(b, f(b))` を通る直線とx軸の交点を次の近似解とします。収束は超線形（約1.618次）ですが、近似解が区間の外に出るなど、不安定になることがあります。

3.  **逆2次補間 (Inverse Quadratic Interpolation):** 3つの点 `(a, f(a))`, `(b, f(b))`, `(c, f(c))` があるとき、`x` を `y=f(x)` の関数とみなし、2次関数を当てはめて補間します。具体的には、ラグランジュ補間多項式を用いて `x` を `y` で表現し、`y=0` となる `x` を求めます。

    `x = a * (y - fb)(y - fc) / ((fa - fb)(fa - fc)) + b * (y - fa)(y - fc) / ((fb - fa)(fb - fc)) + c * (y - fa)(y - fb) / ((fc - fa)(fc - fb))`

    `y=0` を代入することで、次の近似解 `s` が得られます。この手法は収束がさらに速い（約1.839次）ですが、3点が同一直線上にある場合などに失敗する可能性があります。

Brent法では、各ステップでこれらの手法の中から最も効率的で安定したものを選択します。

### 2.2. 実装 (`brentq_impl`)

`ellphi` プロジェクトの `src/ellphi/_tangency_cpp_impl.cpp` に実装されている `brentq_impl` は、このBrent法の古典的な実装です。コード内では、3つの点 `a`, `b`, `c` とその関数値 `fa`, `fb`, `fc` を保持し、逆2次補間と二分法を条件に応じて切り替えながら、許容誤差 `tol` 内に根を探索します。

## 3. Brenth: 双曲線外挿法

### 3.1. 数学的原理

`brenth` は、`brentq` の変種であり、逆2次補間の代わりに **3点有理補間 (3-point Rational Interpolation)**、または双曲線外挿 (Hyperbolic Extrapolation) とも呼ばれる手法を用いる点が最大の違いです。この手法は、J.C.P. Bus と T.J. Dekker の1975年の論文 "Two Efficient Algorithms with Guaranteed Convergence for Finding a Zero of a Function" で提案された "Algorithm M" に基づいています。

3点有理補間では、3つの点 `(b, f(b))`, `(a, f(a))`, `(d, f(d))` に対して、以下の式を用いて次の近似解を求めます。

まず、一次分割差分 `f[x1, x2] = (f(x1) - f(x2)) / (x1 - x2)` を定義します。
次に、以下の補助的な変数 `α` と `β` を計算します。
`α = f[b, d] × f(a)`
`β = f[a, d] × f(b)`

これらの `α` と `β` を用いて、次の近似解 `r` は以下のように定義されます。

-   `β ≠ α` の場合: `r = b - β(b – a) / (β – α)`
-   `β = α ≠ 0` の場合: `r = a`
-   `β = α = 0` の場合: `r = 0`

この手法の主な利点は以下の通りです。

*   **平方根計算の回避:** 逆2次補間では、計算過程で平方根が必要になる場合がありますが、この有理補間ではそれが不要です。
*   **複素数領域の回避:** 実数解を求める際に、補間計算の途中で複素数領域に入るリスクを避けられます。
*   **同等の収束次数:** 逆2次補間と同等の収束次数（約1.839次）を持つと報告されています。

### 3.2. 実装 (`brenth_impl`)

`ellphi` プロジェクトの `src/ellphi/_tangency_cpp_impl.cpp` に実装された `brenth_impl` は、`brentq_impl` の堅牢な構造をベースに、補間ステップを3点有理補間に置き換えたものです。

-   **ヘルパー関数の利用:** 補間処理は、独立したヘルパー関数 `rational_interp` が担当します。この関数は、`b`（現在の最良近似点）、`a`（根を挟んで反対側の点）、`c`（1つ前の `b` または `a`）の3点を入力として、次の近似解を計算します。
-   **安全策 (Safeguard):** 計算された近似解は、`brentq` と同様の厳格な安全策ロジックによって評価されます。補間結果が不安定であったり、収束を十分に速めないと判断された場合は、より確実な二分法が実行されます。
-   **ハイブリッドアプローチ:** このハイブリッドなアプローチにより、有理補間の高速な収束性を活用しつつ、アルゴリズム全体の安定性と収束保証を維持しています。実装は成功し、既存のテストスイートをすべてパスしています。

## 4. 主な違いの要約

| 特徴 | `brentq` | `brenth` |
| :--- | :--- | :--- |
| **補間手法** | 逆2次補間 | 3点有理補間 (双曲線外挿) |
| **元論文** | Brent (1973) | Bus & Dekker (1975) |
| **利点** | 広くテストされ、信頼性が高い | 平方根計算が不要、複素数領域を回避 |
| **プロジェクトでの実装** | **実装済み** | **実装済み** |

## 5. 結論

`brentq` と `brenth` は、それぞれ逆2次補間と3点有理補間という異なる戦略を採用していますが、`ellphi` プロジェクトでは両者ともに堅牢な実装が完了しています。これにより、ユーザーは問題の特性に応じて、より適切な根探索アルゴリズムを選択することが可能になりました。今後の課題として、特定の関数に対する両メソッドの性能を詳細に比較するベンチマークの拡充が考えられます。
